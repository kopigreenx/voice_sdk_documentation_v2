Introduction

What is SocioVoice SDK and how does it work?

Introduction

SocioVoice SDK is a JavaScript library for embedding voice calls into web apps via the Sociomile contact-centre platform. Add it to your page, supply credentials, and you get outbound dialling, inbound call handling, agent state management, and real-time events — without touching SIP, WebSockets, or audio plumbing directly.

Key features

  • Outbound calls — dial by phone number, send DTMF, hold/unhold, mute/unmute, hang up
  • Inbound calls — answer or reject, hold, transfer, send CSAT surveys
  • Agent management — toggle ready/not-ready state, start and end break sessions
  • Real-time events — single sociomileEvent listener covers auth, SIP, call lifecycle, WebSocket, and device changes
  • Audio device control — enumerate, select, and switch microphone/speaker at runtime
  • Call quality monitoring — optional per-call audio stats (MOS, jitter, packet loss) emitted every 2 seconds

Supported environments

EnvironmentHow to load
Browser (<script>)UMD bundle via CDN or local dist/
ES Module (Vite, Webpack, Rollup)import from dist/esm/ or the npm package
CommonJS (Node.js)require() from dist/cjs/ or the npm package
SIP and WebRTC audio require a real browser environment. The Node.js CommonJS build is suitable for server-side tooling (event forwarding, webhooks) but cannot place or receive calls.

Architecture overview

Your app
  └─ new Init({ base_url, secret_key })
       │
       ├─ 1. checkAuth()       → validates secret_key with Sociomile API
       ├─ 2. sipInit()         → registers SIP UA (WebRTC)
       ├─ 3. initWebSocket()   → subscribes Pusher channel for agent events
       │
       └─ emits 'sociomileEvent' for every state change

.start() runs all three steps in order. Once on_registered fires, the SDK is ready to dial or receive calls.

 

Installation

Install SocioVoice SDK via npm, yarn, or CDN.
