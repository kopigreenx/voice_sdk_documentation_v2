Inbound Calls

Receive, answer, hold, transfer, and send CSAT for inbound calls.

Inbound Calls

How inbound calls work

The SDK uses a persistent WebSocket (Pusher) connection established by sdk.start(). When a call arrives at the agent's extension, the platform pushes an on_incoming_call event. The agent must be in Ready state (sdk.agentReady()) before the platform routes calls to them.

WebSocket push → on_incoming_call → sdk.answerCall() → on_inbound_confirmed (audio active)
The agent must call sdk.agentReady() and receive on_agent_login_success before inbound calls are routed. Calls will not arrive while the agent is Unready or on a Break.

Answering and rejecting

sdk.on('sociomileEvent', (event) => {
  if (event.event_name === 'on_incoming_call') {
    const { from_extension, from_display_name } = event.data
    console.log(`Incoming call from ${from_display_name} (${from_extension})`)

    // Answer
    sdk.answerCall()

    // — or reject —
    // sdk.rejectCall()
  }
})
MethodDescription
sdk.answerCall()Answers the ringing inbound session and starts audio
sdk.rejectCall()Rejects and terminates the ringing session

Once answered, on_agent_call_linked fires with call metadata (call_id, uniqueid, phone, agent_number). When audio is confirmed, on_inbound_confirmed fires.

Hanging up

await sdk.hangupInbound()

Calls the platform API to unlink the call, emits on_agent_call_unlink_initiated, then on_agent_call_unlinked with the API response.

Hold / Unhold

await sdk.holdInbound()   // puts caller on hold
await sdk.unholdInbound() // resumes

Events under type: 'api_inbound_event', event_group: 'agent_hold':

event_nameDescription
on_hold_call_successCall placed on hold
on_unhold_call_successCall resumed

Blind transfer

await sdk.transferCallTo('1234')

Transfers the active inbound call to extension '1234'. Emits on_transfercall_success on success, on_transfercall_failed if no extension is provided.

CSAT

Send a customer satisfaction survey to the caller before ending the call:

await sdk.sendCsat('9000')  // '9000' is the CSAT IVR extension

Emits on_csat_success on success, on_csat_failed if the extension is missing.

Call sdk.sendCsat() before sdk.hangupInbound(). The CSAT transfer routes the caller to the survey IVR — hanging up first will drop them instead.

Full example

import SocioVoice from 'sociomile-voice-sdk'

const sdk = new SocioVoice({
  base_url: 'api.yourdomain.com',
  secret_key: 'YOUR_SECRET_KEY',
})

await sdk.start()

// Set agent ready to receive calls
await sdk.agentReady()

sdk.on('sociomileEvent', async (event) => {
  switch (event.event_name) {

    case 'on_agent_login_success':
      console.log('Agent is ready — waiting for calls')
      break

    case 'on_incoming_call':
      console.log('Incoming:', event.data.from_display_name)
      sdk.answerCall()
      break

    case 'on_inbound_confirmed':
      console.log('Call active — audio started')
      break

    case 'on_inbound_ended':
      console.log('Call ended')
      break
  }
})

// Example: hold, resume, send CSAT, hang up
async function wrapUpCall() {
  await sdk.holdInbound()
  await new Promise(r => setTimeout(r, 5000))
  await sdk.unholdInbound()

  // Route caller to CSAT survey, then disconnect
  await sdk.sendCsat('9000')
  await sdk.hangupInbound()
}
